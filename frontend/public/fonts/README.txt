Dianora font — self-hosted display font
=======================================

Dianora is NOT on Google Fonts, so it must be self-hosted here.

To activate it:
  1. Obtain the Dianora font file (you have a license / personal-use only).
  2. Drop it into THIS folder named exactly one of:
        Dianora.woff2   (preferred — smallest)
        Dianora.otf
        Dianora.ttf
  3. Refresh the app. It switches on automatically.

Until a file is present, all display headings fall back to Montserrat
(no errors — just a graceful fallback).

Note: Dianora is a script/handwriting font. It looks great on the big hero
headline and logo, but it is hard to read for small UI text. If you want it
scoped to only the hero (and Montserrat for the rest), just ask.
